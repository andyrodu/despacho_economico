# Semana 1 – Framing (Simulador Despacho Económico MX)

## User journey
1) Elegir sistema: SIN / BCA / BCS.
2) Descargar demanda horaria desde CENACE.
3) Definir capacidades por tecnología (base y caso 2026).
4) Ajustar costos variables con sliders.
5) Correr despacho económico y visualizar resultados (despacho, costo total, precio 
marginal).
6) Comparar escenarios predefinidos.

## Supuestos (MVP)
- SIN, BCA y BCS modelados como sistemas independientes.
- Horizonte horario.
- Herramienta educativa que simplifica el despacho real.
- Costos variables ajustables por tecnología.
